# Manufacturing Resource Allocation Semantic NLP Matcher

A medium-to-advanced Python machine learning mini project by Mithilesh.

## Domain

- Industry: manufacturing
- Focus: resource allocation
- Project type: semantic_nlp

## What I Built

- Prepared a synthetic but realistic dataset for the use case
- Trained a machine learning workflow using Scikit-learn
- Generated metrics and report files
- Created a chart image for quick review
- Added a screenshot-friendly HTML preview page
- Added a pytest check to verify the project output

## Tech Stack

- Python
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- Pytest
