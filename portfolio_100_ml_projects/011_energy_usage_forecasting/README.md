# Energy Usage Forecaster

A compact machine learning project by Mithilesh based on the topic: **energy usage**.

## Project Type

forecasting

## What I Built

- Prepared a small dataset for the project idea
- Trained a Python machine learning workflow
- Generated metrics and report files

- Added a simple HTML preview page for screenshots

## Tech Stack

- Python
- NumPy

- Matplotlib
- Pytest
